Hosting the Software is **strictly prohibited**, except under the narrow Development exception below.

1. The instance exists solely to test or debug changes;
2. The instance is not advertised, indexed, listed, or discoverable;
3. No gameplay, roleplay, persistent progression, or community activity occurs;
4. Access is limited to active developers working on the code;
5. The instance exists only for the minimum time required to validate changes;
6. The instance is not represented as a server, shard, or playable environment.
